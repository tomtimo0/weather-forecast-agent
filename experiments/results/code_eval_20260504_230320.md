### mode=llm_with_code（2 条失败）

- **diff_001_max_diurnal** [diff]
  - 期望：`{'date': '2025-09-18', 'tempDiff': 22.7}`（type=date_with_value）
  - 实际：`{'date': '2025-09-18', 'range': 22.7}`
  - 代码执行成功但结果错误（潜在算法 bug）
  - reasoning: 遍历每日数据，计算日较差（tempMax - tempMin），记录最大日较差对应的日期和差值，返回日期与日较差。
  - code:
```python
def compute(data):
    daily = data["daily"]
    max_range = -1
    max_date = None
    for day in daily:
        diff = day["tempMax"] - day["tempMin"]
        if diff > max_range:
            max_range = diff
            max_date = day["date"]
    return {"date": max_date, "range": round(max_range, 1)}

```

- **diff_003_yoy_precip** [diff]
  - 期望：`92.4`（type=scalar）
  - 实际：`None`
  - 代码执行失败：运行时异常：NameError: name 'next' is not defined
  - reasoning: 从 monthly 列表中分别取出今年(2025)6月和去年(2024)6月的总降水量，计算差值并保留1位小数。
  - code:
```python
def compute(data):
    monthly = data["monthly"]
    # 找到今年6月和去年6月的降水数据
    this_year = max(entry["year"] for entry in monthly)
    last_year = this_year - 1
    precip_this = next(e["totalPrecip"] for e in monthly if e["year"] == this_year and e["month"] == 6)
    precip_last = next(e["totalPrecip"] for e in monthly if e["year"] == last_year and e["month"] == 6)
    diff = precip_this - precip_last
    return round(diff, 1)
```
