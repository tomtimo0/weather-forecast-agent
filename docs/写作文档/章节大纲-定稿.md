## 附：论文正文写作风格规则（降低 AI 查重率）

以下规则适用于本论文所有章节正文。每节起草前应回顾，每节定稿前应自检。

### A. 排版与强调

- 正文中间一律不使用加粗（不用 `\textbf{}`）。需要强调时，把要点单独成句。
- 不使用斜体强调（不用 `\textit{}`）。中文论文中斜体不是常规修辞手段。
- 列表项的标题不加粗。直接以"通路 A：" "通路 B：" 这种方式起首即可，
  或干脆把列表展开为正文连贯段落。
- 等宽字体 `\texttt{}` 仅用于真实代码标识符或文件路径，不用于一般概念。

### B. 标点节制

- 少用中文双引号。引用术语或自定义概念时，全文首次出现可加，之后纯文本。
- 不使用括号引出例子。把"（如 A、B、C）"改为"例如 A、B、C"或独立成句。
- 数据范围、单位、缩写定义等技术性括号仍可保留，例如 `100~249.9 mm`、
  `(Recall@5 = 97.7\%)`。
- 减少破折号。需要解释时改用句号或冒号断句。

### C. 句式

- 避免"首先 / 其次 / 最后"三段式套话。改用"第一 / 第二 / 第三"或者直接
  分段叙述。
- 避免"非常 / 显著 / 大幅 / 突出 / 特别"这类带情绪的副词。给数字让数字说话。
- 避免"我们 / 笔者"。本科论文用"本文 / 本节 / 本章"自指。
- 避免长定语堆叠。一句话超过 50 字考虑断句。

### D. 与素材文档的关系

- 5 份论文素材文档是\ **数据来源**\ ，不是文字底稿。
- 起草时只引用素材里的数据、图表、用例编号，重新组织语言。
- 同一数据点在不同章节出现时，用不同句式表达，避免段落级雷同。

### E. 引用规范

- 临时使用 `\cite{ref<开题报告编号>}` 格式。论文骨架稳定后统一改为有
  意义的 BibTeX key。
- 单段引用密度建议 1~3 处，避免一段堆 5 篇以上。
- 国家标准（GB/T、GB）以非引用形式出现（直接写"GB/T 28592-2012"），
  不进 `\cite{}`。
