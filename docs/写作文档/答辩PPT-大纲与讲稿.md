## 第 2 页｜研究背景与三类技术问题（约 45 秒）

### 版式建议
- 左 55% 文字、右 45% 配图。

- 三类技术问题用三种颜色区分，便于后续页面回指。

### PPT 文字

**研究背景**
气象预报数据是支撑国民经济与社会发展的重要信息资源，但当前面临两类深层次技术鸿沟：不同平台的接口、字段、错误码不一致带来的**数据异构性**；数值数据到自然语言决策语义之间的**认知鸿沟**。

**三类技术问题**
- **气象任务指令解析**——用户口语化输入到结构化 API 参数的鸿沟
- **气象数据异构特征**——多源 API 字段命名、错误码、单位体系不统一
- **大语言模型数值与逻辑幻觉**——引用编造、分级编造、数值漂移

**研究目标**
设计并实现一个把上述三类问题在工程层面闭环消解的单智能体系统。

### 讲稿

> 气象预报数据是支撑国民经济与社会发展的重要信息资源，但其获取与分析当前面临两类深层次技术鸿沟：一类来自不同机构平台的接口、字段、错误码不一致带来的数据异构性，另一类来自数值数据到自然语言决策语义之间的认知差距。与此同时，把大语言模型直接套到气象数据分析上，会出现引用编造、分级编造、数值漂移等严重的可信度问题。本文据此把课题归纳为三个具体研究问题：气象任务指令解析、气象数据异构特征处理，以及大语言模型的数值与逻辑幻觉。本文的目标，就是设计一个能在工程层面把这三类问题闭环消解的单智能体系统。

## 第 5 页｜关键技术二：双通路 RAG 与语义桥接（约 60 秒，全文核心）

### 版式建议

### PPT 文字

**通路 A：混合检索 + 可调权重融合**——承担概念性查询的高召回任务
- 60 条检索评测集：**Top-1 命中 85.0%，MRR 0.908**

**通路 B：5 类确定性分级器 + `grade_id` 硬链接**——承担数值到等级到标准引用的精确归属

- 桥接后：注入 `grade_id=heat_level_2`、`citation="GB/T 51120-2015"`、`grade_name="高温二级预警"` 三段结构化标签

### 讲稿

> 第二项也是本文最核心的关键技术，是双通路 RAG 架构。通路 A 把向量检索与 BM25 词法检索以可调权重融合，承担概念性查询的高召回任务，在 60 条检索评测集上 Top-1 命中率 85.0%、MRR 0.908。通路 B 由 5 类确定性分级器加 grade_id 硬链接构成，承担数值到等级再到标准引用的精确归属任务，在 71 条桥接评测集上，等级编号准确率与权威标准引用真实性同时达到 100%，与大语言模型自由发挥的基线在严格命中率上形成 74.6 个百分点的差距。这一组结构化标签从根本上消解了大语言模型在条款编号上的编造问题。

## 第 6 页｜关键技术三：代码生成 + 受限沙箱（约 35 秒）

### 版式建议
- 左 55% 流程图：用户统计请求 → LLM 生成 `compute(data)` 顶层函数 → 受限沙箱执行 → 结构化返回。
- 沙箱四重约束用四个小盾牌图标排列：白名单 builtins、白名单模块、墙钟超时、结构化错误捕获。
- 右 45% 放对照柱形图：18 条评测中 "代码执行档 88.9%" vs "LLM 自由直算 66.7%"，差值 +22.2 pp 用红色标注。

### PPT 文字

**轻量沙箱设计**：LLM 生成 `compute(data)` 顶层函数，在四重约束下执行
- 白名单 `builtins` —— 切断 `eval` / `exec` / `__import__` 等危险入口
- 白名单模块 —— 仅允许 `math` / `statistics` / `datetime`
- 墙钟超时 —— 单次执行 ≤ 5 秒，超时自动终止
- 结构化错误捕获 —— 异常以 JSON 形式返回给主智能体重试

**评测结果**：18 条覆盖 6 类统计模式的评测集
- **代码执行档数值准确率 88.9%，比大语言模型自由直算高出 22.2 个百分点**
- 失败模式分析揭示了 LLM 在伴随状态维护与离散计数任务上的内在边界

### 讲稿

> 第三项关键技术是基于代码生成与受限沙箱的确定性统计分析。轻量沙箱由大语言模型生成 compute(data) 顶层函数，在白名单 builtins、白名单模块、墙钟超时、结构化错误捕获四重约束下执行。在 18 条覆盖 6 类统计模式的评测集上，代码执行档数值准确率 88.9%，比大语言模型自由直算高出 22.2 个百分点，失败模式分析也进一步揭示了大语言模型在伴随状态维护与离散计数任务上的内在边界。
